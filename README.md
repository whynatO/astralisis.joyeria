# Astralisis Joyeria

Sitio web estático de joyería alternativa con:

- Catálogo dinámico de productos.
- Filtros por categoría (acero, resina y plástico).
- Carrito lateral funcional con contador, agregado y eliminación.
- Formulario de contacto con confirmación en pantalla.

## Ejecutar localmente

Como es una web estática, puedes abrir `index.html` directamente o servirla con un servidor simple:

```bash
python3 -m http.server 8000
```

Después abre: <http://localhost:8000>
